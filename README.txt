Instalação:
- Criar venv (python -m venv venv)
- Ative o venv (./venv/Scripts/activate)
- Talvez seja necessario permitir execução de script antes de ativar o venv (Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy AllSigned)
- Instalar os requirements a partir do txt (pip install -r requirements.txt)
- Rodar os testes com pytest
